Lưu ý bảo mật quan trọng:

Mã Refresh Token dưới đây chỉ hiển thị 1 lần duy nhất trên trang này và sẽ tự động bị xóa khỏi phiên làm việc ngay khi thầy/cô tải lại trang hoặc rời đi. Hệ thống không lưu trữ mã này trong mã nguồn hay cơ sở dữ liệu.

Hướng dẫn thêm vào Render (Để lưu trữ vĩnh viễn):
  1. Nhấn nút "Sao chép Token đầy đủ" ở trên.
  2. Truy cập Render Dashboard → Chọn Web Service timebankEDU → Chọn tab Environment.
  3. Thêm biến môi trường mới:
    Key: GOOGLE_REFRESH_TOKEN
    Value: [Dán mã vừa copy vào đây]
  4. Nhấn Save Changes để hệ thống tự động duy trì kết nối Google Drive 5TB vĩnh viễn.
